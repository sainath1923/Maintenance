# Stores Module

This module provides a dashboard, stock items, and item requests for the stores department. It is structured similarly to the procurement module and uses React with Vite for the frontend.

## Features
- Dashboard
- Stock Items
- Item Requests

## Getting Started

1. Install dependencies:
   ```sh
   npm install
   ```
2. Start the development server:
   ```sh
   npm run dev
   ```

## File Structure
- `src/App.jsx`: Main app with routing
- `src/Dashboard.jsx`: Dashboard page
- `src/StockItems.jsx`: Stock items page
- `src/ItemRequests.jsx`: Item requests page
- `src/styles.css`: Basic styles
